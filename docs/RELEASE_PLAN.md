# Publication, Feedback, and Career Development Plan

Updated: 2026-11-13

## Purpose
Publish a credible and useful technical portfolio while building relationships with measurement practitioners. Report quality and reproducibility before reach and engagement.

| Trigger | Candidate public artifact | What it teaches | Evidence gate |
|---|---|---|---|
| M0 recovery | Brief, clearly labeled progress note: why synthetic truth and internal QA are different | Data integrity is necessary, not sufficient for causal measurement | Accurate recovered-artifact and reproducibility record; no premature model claim |
| M1 integration | DGP explainer and schema diagram | One coherent transaction, exposure and counterfactual simulation | Committed source and pilot reproduction |
| M2 release | Technical test post / runnable QA examples | Negative tests, ledger reconciliation and null-effect invariants | Public reproducibility + adversarial checks |
| M3 MMM | MMM article or notebook walkthrough | Adstock, saturation, uncertainty, calibration, causal limits | Verified model implementation and diagnostics |
| M4 MTA | Attribution bias article | Why path credit differs from incrementality | Transparent baselines, documented selection and missingness |
| M5 experiment | Simulated geo lift study | Paired randomization, power, confidence intervals, interference limitations | Independent experiment analysis and uncertainty |
| M6 triangulation | Full capstone + LinkedIn/Medium paper | When estimates disagree, what evidence changes a budget decision? | Aligned estimands, tested benchmarks, caveats |
| M7 validation | Portfolio walkthrough, practitioner critique, project showcase | Can outsiders reproduce and challenge the work? | Replication instructions, review record |

## Distribution principles
- Share original insight plus code/evidence, not marketing slogans.
- Ask one narrowly framed methodological question per practitioner outreach.
- Keep private contact and recruiting details outside the public GitHub repository.
- Capture external critiques as anonymized design feedback only with permission.
- Record reach (stars/forks/reads), quality (technical comments/replication), relationships (replies/conversations), and career outcomes privately, without exposing contacts.
